# 🚀 Jira Sprint Velocity & Workload Distribution Analysis

## 📌 Business Problem Statement
Unbalanced workload distribution across Agile team members causes bottleneck delays and reduces sprint velocity. This project tracks committed vs. completed story points to measure execution efficiency.

## 🛠️ Tech Stack & Tools
- **Language:** Python (Pandas)
- **Concepts:** Agile Metrics, Velocity Rate, Resource Allocation Analysis

## 📊 Key Insights & Business Impact
- **Sprint Completion Rate:** Calculated overall velocity efficiency across committed story points.
- **Workload Bottleneck:** Identified work-in-progress distribution imbalances to adjust future sprint capacity planning.
